# 章节开发指引（每章开发必读 · 单一入口）

## Part 0 · 十条原则

1. **16:9 固定舞台**：内容设计在 1920×1080，外层 `transform: scale` 缩放，无响应式断点。
2. **全局 step 计数器**：章节是 `step` 的纯函数，无定时器、无命令式状态。
3. **每步独占整屏**：`if (step === N) return <FullScene />`，一步一聚焦。
4. **口播节拍 = step**：一节拍 = 一 step = 一聚焦想法。
5. **隐藏边角控件**：进度条 / 翻页器默认 `opacity: 0`，悬浮才出现。
6. **舞台无 chrome**：无 header / footer / 页码 / 品牌条。
7. **内容驱动动画**：先找内在动作（数字递增 / 连线自绘 / 对比切开），找不到才入场动画兜底；持续微动慎用。
8. **多点逐个揭示**：1 项 = 1 step，禁同步 stagger 上 N 项。
9. **整片同一主题**：颜色 / 字体走 token，其它尺度章节自由。
10. **双源原则**：script 定节拍，article 定画面密度。

## Part 1 · 开工 5 问（写每章前自问）

1. 这章核心是什么？一句话说清。
2. 每步"演什么"？哪步有视觉动作？
3. 清单 / 列表项要不要逐个揭示（1 项 1 step）？
4. 画面细节够不够密（比口播多）？回 article 抽了什么挂上来？
5. 每步动画时长 ≤ 该步口播时长吗？

## Part 2 · 关系 → 动作决策树（内容驱动动画）

先找内容的内在关系，再映射动作：

| 内在关系 | 视觉动作 |
|---|---|
| 数量 / 增长 | 数字递增、横条生长、排名交换 |
| 顺序 / 流程 | 节点依次点亮、连线自绘 |
| 对比 / 对立 | 一刀切开、聚光灯扫过、左右对照 |
| 结构 / 层级 | 目录树展开、嵌套点亮 |
| 时间 / 叙事 | 蒙太奇式场景切换 |

找不到内在关系 → 用入场动画兜底（fade / wipe / 弹簧），但整章不能只靠这一种。

## Part 3 · 视觉工具箱

每章**至少 1~2 处** CSS / SVG / Canvas / JS 视觉演示（**禁整章纯文字**）：
数字递增 / 横条生长 / 排名交换；流程节点点亮 / 连线自绘；对比切开 / 聚光灯 / 变形；
粒子聚拢 / 噪声流动 / 字符雨；模拟终端 / AI 对话 / 文件目录树。

判断标准：**不像 PPT**（无页眉页脚、主视觉突出）、**看起来舒服**（大字、留白、不塞满）、**有冲击**（画面在演事情，不是堆字）。

## Part 4 · 时长参考

- 中文口播 ≈ 4 字/秒；单 step 估时 3~10s。
- **动画时长 ≤ 该 step 口播时长**——Auto 模式按音频结束推进，没有"等动画跑完"兜底。
- 动画太长 → 三选一：写更长口播 / 拆 step / 调动画速度。

## Part 5 · 反 AI 味反模式

全不要：紫粉 / 蓝紫对角渐变背景、圆角卡片 + 彩色左边框、渐变按钮 + 大圆角药丸、
emoji 当图标、假数据 / 假 logo / 假"X 万用户"、整章 N 步同一种入场动画、
每步 ken burns / 光晕呼吸 / 持续闪烁、每屏右下角 mono 角标。

缺素材：**承认缺**，用 placeholder 占位卡（一张写着 "image · 16:9 描述" 的卡片按真实比例留位）。
不要 emoji 凑、不要无关图凑、不要编数字。

## Part 6 · 代码硬规则

**必须用 token（换主题不破的底线）**：

- 颜色：`--shell` / `--surface` / `--surface-2` / `--surface-3` / `--text` / `--text-2` /
  `--text-mute` / `--text-faint` / `--rule` / `--accent` / `--accent-soft` / `--accent-glow`
  —— **禁硬编码 hex / rgb / 颜色名**
- 字体家族：`--font-display-cn` / `--font-display-en` / `--font-body` / `--font-mono`
  —— **禁硬编码字体名**
- primitive class 自动接入主题性格，**不要在章节 CSS 重定义**：`.hero-num` / `.rule` /
  `.card` / `.stage-frame`

**可硬编码（章节自由）**：字号 / 间距 / 动画时长 / 缓动 / keyframe / 边框宽度 / 字距 / gap / grid 尺寸。

**其它红线**：

- 不用 `setTimeout` / `setInterval` 驱动动画，用 CSS keyframes
- 章节内可交互元素加 `data-no-advance`，否则点它会被舞台误推进 step
- 章节物理隔离：每章独立文件夹、独立 CSS 类前缀（`.cd-` / `.mg-` / ...），不跨章 import

**`narrations.ts`（强制，唯一真相源）**：

- 与 `<Chapter>.tsx` 同目录；数组长度 **=** 章节代码 `if (step === N)` 出现的最大 N + 1
- 每元素 = 该 step 口播文本（来自 script.md 对应段，**语义一致**，可微调标点 / 断句适配 TTS，不漏关键短语）
- 无声过场 step 用空串 `""`（Auto 模式按字数估时撑过）
- 写错 / 漏写 = 录屏对不上嘴

## Part 7 · 完工自检（每章写完**强制**，不可跳过）

写完 + 在浏览器点完一遍后逐项过：

- [ ] 每章 ≥ 1~2 处 CSS / SVG / Canvas / JS 视觉演示
- [ ] 不同 step 主导动作不一样（全章一种 = 重做）
- [ ] 清单 / 列表 1 项 = 1 step，逐项揭示
- [ ] 画面信息比口播稿多（回了 article 抽细节）
- [ ] 无紫粉渐变 / 圆角彩色边框 / emoji / 假数据 / 假 logo
- [ ] 颜色字体全 token；hero 数字 / 卡片 / 分割线 / 舞台用 primitive class
- [ ] 无小号字体 / 大量纯文字 / 页眉页脚
- [ ] 章节独立 CSS 前缀，未跨章 import，未改 chapters.ts 之外共享文件
- [ ] `narrations.ts` 存在且长度 = 最大 step N + 1；每条文本与 script.md 语义一致
- [ ] 每 step 动画时长 ≤ 口播时长（字数 ÷ 4 ≈ 秒）
- [ ] `npx tsc --noEmit` 通过

**执行方式**（硬性自检协议）：优先 `spawn_teammate` / `subagent` 开 reviewer，传入本章代码路径 + 本清单，
逐项核查出结论（pass/fail + 证据）；否则自己严格逐项。**先按 fail 项改完，再向用户汇报本章交付。**
任一未过 → 回去改，不"先放着以后修"。

## Part 8 · 常见反馈速查

先定位层级，再改最小切片，**不重做整章**：

| 反馈 | 层级 | 改法 |
|---|---|---|
| 太快 / 太慢 / 信息太薄 | 节奏 | 调 step 切分或口播 |
| 动画不对 / 像 PPT | 视觉 | 回 Part 2 找内在关系 |
| 细节不够 / 画面太空 | 内容 | 回 article 抽，挂到画面 |
| 换主题就破 | 代码 | 查硬编码 hex / 字体名 |
| 录屏对不上嘴 | 代码 | 补 / 修 narrations.ts |
