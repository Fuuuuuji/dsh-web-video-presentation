# 文章 → 口播稿风格指南

把书面文章转成"说出来不别扭"的口播稿，默认 **B 站风格**，其他平台变体见末尾。

> **英文口播稿**（用户原文是英文，或要求英文）→ 改读 [`SCRIPT-STYLE-EN.md`](SCRIPT-STYLE-EN.md)：英文有自己的节奏（150 wpm）、修辞（rule of three）和 AI 指纹词，规则与本文不同。

## 三条底线（任一不过，整稿重写）

1. **信息保留度 ≥ 60%**：口播稿是"换说法"不是"摘要"。删冗余 / 修饰可以，删事实 / 数据 / 案例 / 论证链不行。
2. **去 AI 味**：即使短句化 / 口语化，假共情 / 假深刻 / 自我标榜 / 万能模板 / 排比堆砌念出来仍然一耳朵是机器。
3. **保持原文语言**：除非用户要求翻译，`script.md` 保持用户输入主语言；中英混排保留术语 / 引用 / 产品名 / 代码。"B 站 / YouTube 风格"只调节奏结构，不换语言。

## 最高原则：信息保留度 ≥ 60%（删减 ≤ 40%）

- `len(script.md) ÷ len(article.md) ≥ 0.6`（中文按字符计；代码块 / Markdown 标记不计）
- 关键事实（数字 / 名称 / 时间 / 论断）逐项对得上；论证链（前提→结论 / 因果 / 对比）换说法但不跳步
- **可大幅压缩**：套话开场 / 重复总结 / 学术铺垫 / 引文书目 / 客套结语
- **禁压缩**：关键数字（可"翻译成感受"但保留原值旁注）、具体案例 / 故事、多步论证中间步骤、反方观点 / 限制 / 例外
- 原文太长 → 不硬塞，**告诉用户**："X 字按 60% 留存最少 ~Y 分钟，要么拉长要么拆集"，不擅自缩到 30% 假装做完

## B 站 8 条原则（形式层）

1. **口语化**：书面语换口语（综上所述→所以你看；该工具旨在→这玩意是用来；据相关资料显示→我查了下）。标准：念出来会不会"这人怎么这么端着"。
2. **短句 ≤ 20 字**：长句拆短句，逗号优先于复合句。
3. **第二人称**：多用"你 / 我们"，少用"用户 / 读者 / 本文将介绍"。
4. **开头有钩子（cold open）**：3 秒砸到脸上。悬念（"我以为是 bug，结果…"）/ 反差（"这玩意以前 3 小时，现在 30 秒"）/ 利益（"学会这招，开会再也不怕"）。**禁**："大家好今天讲讲"、PPT 标题感、"在开始之前"铺垫、"我知道你最近很纠结"假共情、"接下来颠覆你的认知"自我加权。
5. **节奏停顿用 `---`**：一个聚焦想法 = 一个 `---` = 一个 step 边界，一行一个 idea。
6. **数字翻译成感受**：观众听到具体百分比会走神，除非数字本身是冲击点（"涨了 20 倍"保留）。准确率提升 47%→几乎快了一倍；覆盖 120 国→全世界基本到处都用。
7. **不堆结构词 / 万能模板**：禁"首先 / 其次 / 最后 / 接下来看三点 / 总结一下"；禁"说白了 / 本质上 / 底层逻辑 / 一句话总结 / 归根结底"。做法：融进自然过渡或直接砍掉。
8. **具体例子优先**：抽象→具体（"性能优越"→"我那台 5 年前的旧电脑跑得动"）。举例从"我"出发。

## 去 AI 味五类（风骨层）

写完专门扫一次逐条砍。唯一标准：**这话念出来，真人会这么说吗？**

| 类别 | ❌ 指纹 | ✓ 改法 |
|---|---|---|
| 一、假共情 | "我知道你最近很纠结" / "你是不是也有" / "我懂你的感受" | 直接抛事实/钩子；要共情用具体的"这个坑我也踩过" |
| 二、假深刻 | "恰恰相反" / "反而是" / "正是因为" | 去掉转折直接说结论；去掉后观点平淡=它本来就平淡，换内容 |
| 三、自我标榜 | "我必须认真说" / "颠覆你的认知" / "这段一定要听完" | 直接说；好观点不预热 |
| 四、万能模板 | 开头"说白了/本质上"；过渡"一句话总结/换句话说"；结尾"以上就是本期内容/希望对你有帮助" | 直接说那句话；结尾用具体 CTA |
| 五、排比堆砌 | 连续 ≥3 句结构一样（"不躲，不藏，不绕，不逃"） | 保留最有信息量的一两个，其余砍掉或换成具体例子 |

细节禁忌：无 emoji（除非用户要求）、无括号补充（"这个模型（一种 transformer 架构）"念不出来）、无《书名号》引文格式、不堆"哈哈哈"、少用有半年保鲜期的网络梗。

## 平台风格变体

| 平台 | 基调 | 单句长 | 钩子节奏 | 信息密度 |
|---|---|---|---|---|
| B 站（默认） | 自来熟、有段子、快 | ≤20 字 | 3 秒 | 中（5s/idea） |
| 抖音 / 视频号 | 更燃、更短、更冲击 | ≤12 字 | 1 秒 | 高（3s/idea） |
| YouTube long-form | 舒缓、可铺垫 | ≤30 字 | 30 秒铺垫可 | 低（10s/idea） |
| 知乎视频 | 严谨、有逻辑 | ≤25 字 | 5 秒可铺背景 | 中 |
| 小红书 | 闺蜜分享感 | ≤15 字 | 直接结论 | 中 |

> 小红书闺蜜感 ≠ 假共情：区别在**有没有具体场景**。

**主题类型微调**：技术/教程可稍端但口语化（"我们试一下"）；测评/对比要"敢说"（"这个不行"，但敢说≠自我标榜）；新闻/资讯快节奏硬金句；产品/营销忌"吹"（不说"完美/颠覆"，说"我用了一周确实顺手"）；文化/历史/科普放慢，多用"你想象一下"开场。

## 写完后：三层自检（硬性流程）

写完 `script.md` 必须走完自检 → 修改 → 再继续，**禁止写完直接产 outline**。
执行方式：优先 `spawn_teammate` / `subagent` 开 reviewer（传 script.md + 本清单），否则自己严格逐项；拿到结论先改稿再产 outline。

**形式层**：

- [ ] 信息保留度 ≥ 60%（`wc -m` 算比例；关键数字/案例/论证链逐项对照原文）
- [ ] 无 emoji / 《书名号》 / 括号补充 / "据 XX 报告显示"类引文
- [ ] 每句 ≤ 20 字（B 站基准）？第二人称？开头 3 秒钩子？
- [ ] 数字翻译成感受（核心冲击数字保留原值）
- [ ] 无"首先 / 其次 / 最后"结构词；都是具体例子

**风骨层**（最重要）：

- [ ] 全文无"说白了 / 本质上 / 底层逻辑 / 恰恰 / 反而 / 正是因为 / 归根结底"
- [ ] 开头是钩子，不是假共情；无"我必须认真说 / 颠覆认知"自我加权
- [ ] 无连续 ≥3 句排比；结尾是具体 CTA 不是套话
- [ ] 所有"恰恰/反而/正是"句：去掉后意思变了吗？没变就删

**念出来（终极标准）**：挑 3 段真张嘴念。念到"我说不出口"= AI 味；想跳过 = 排比/标榜；想笑出声（因油腻）= 假共情。改完再念，三段都自然为止。

> 去 AI 味不是降质：把"AI 在朗诵"换成"人在聊天"，信息量一个不少。换了之后内容变蠢 = 它本来就蠢，该补内容了。
